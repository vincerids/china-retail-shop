# Дизайн-макеты проекта MILA

Здесь хранятся визуальные материалы для интернет-магазина одежды.

## 📁 Что внутри
- `china-retail-shop.fig` — исходный файл Figma (для редактирования).
- `MILA — магазин одежды.png` — скриншот главной страницы (полный вид).
- `Корзина — панель справа.png` — скриншот выезжающей корзины.
- `Контакты — всплывающая форма.png` — скриншот поп-апа контактов.

## 🎨 Основные цвета
- Фон: `#FFDAB9` (персиковый)
- Кнопки: `#FAEBD7` (кремовый)
- Активная кнопка: `#FF7F50` (коралловый)
