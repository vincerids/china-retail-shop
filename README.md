# China Retail Shop (MILA)

Одностраничный интернет-магазин одежды с корзиной, оформлением заказа и интеграцией с Telegram.

## 🛠 Технологии
- **Frontend:** HTML5, CSS3, JavaScript (Vanilla).
- **Backend:** Node.js, Express.
- **Интеграции:** Telegram Bot API (уведомления о заказах).
- **Деплой:** GitHub Pages (фронтенд), Render (бэкенд).

## 📁 Структура проекта
- `/design` — макеты Figma и скриншоты.
- `/frontend` — клиентская часть (HTML, CSS, JS). *(будет создана после утверждения дизайна)*
- `/backend` — серверная часть (Node.js, Express). *(будет создана после утверждения дизайна)*

## 🚦 Статус проекта
- **Текущий этап:** Дизайн (ожидает утверждения клиентом).
- **Следующий этап:** Верстка и разработка бэкенда.
